# Codex Project Notes

## Project

Waldorf English Pathway is a static, Waldorf-inspired English learning site for Brazilian learners, with Grade 7 as the pilot, lower-grade lessons, a Grade 6 bridge, and a planned Grade 8 pathway.

## First Steps

1. Read `README.md`, `docs/site-architecture.md`, and `docs/CURRENT_STATUS.md`.
2. Keep learner data, Supabase secrets, service keys, and any private account configuration out of Git.
3. Preserve original curriculum wording. Do not copy protected workbook text.
4. Keep the static site usable by opening `index.html` directly unless project docs say otherwise.

## Content Rules

- Waldorf-inspired, not an official Waldorf curriculum.
- EFL-appropriate and scaffolded for Brazilian learners.
- Portuguese support is useful, but learner-facing English practice should remain clear and age-appropriate.
- Use original material, public-domain works, licensed content, or short attributed excerpts only.
